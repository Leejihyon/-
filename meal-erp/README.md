# 위탁급식 운영 ERP (meal-erp)

(주)국제F&S 위탁급식 영양사 업무용 프로그램의 첫 버전입니다.
기존 프로그램의 「위탁 영양사」 메뉴 화면 구성(2026-11-02 캡처 167장)을 기준으로 새로 만들었습니다.
**시연용 샘플 데이터가 들어 있습니다. 업체명·단가·식수·1인분 사용량은 모두 가짜 값입니다.**

## 실행

```bash
cd meal-erp
npm install
npm run dev        # 개발 서버
npm run build      # 배포용 빌드 (dist/)
```

입력한 내용은 브라우저(localStorage)에 저장됩니다. 서버·로그인은 아직 없습니다.
왼쪽 아래 「샘플 데이터로 초기화」로 처음 상태로 되돌립니다.

## 화면

| 화면 | 하는 일 |
|---|---|
| 영양사식단 | 주간 식단표 입력(끼니·요일·형태 켜고 끄기), 지난주 복사, 예상 식재료비 |
| 발주 관리 | 식단표 → 재료별 필요량 → 업체별 발주서(임시 저장·발주 확정·입고 처리·인쇄) |
| 검식일지 | 식단에서 메뉴 자동 채움, 검식 시간·판정 기록, 주간 인쇄 |
| 보존식 | 식단에서 자동 생성(폐기일 기본 +7일), 일괄 생성·삭제, 인쇄 |
| 일마감 | 날짜별 실제 식수·잔반 입력 |
| 월마감 | 업장별 식수·매출·식재료비·손익 집계(인건비·경비는 수기) |
| 영양사 회의자료 | 주간 보고서 작성, 업장별 제출 현황 |
| 업장 관리 | 업장 등록·수정, 끼니별 식수·단가, 업장 인력·입력 권한 |
| 재료·메뉴 관리 | 재료 단가, 메뉴별 1인분 재료, 공급업체, **CSV 가져오기** |

모든 화면 상단에서 업장을 고를 수 있어, 업장을 추가하면 같은 화면이 그대로 동작합니다.

## 계산 방식

- 필요량 = Σ (메뉴의 1인분 사용량 × 끼니별 식수) × (1 + 업장 손실률)
- 발주량은 kg·L는 0.1 단위, 개는 정수로 올림합니다. 화면에서 직접 고칠 수 있습니다.
- 납품 예정일 기본값은 첫 사용일 전날이며, 이미 지났으면 내일입니다.
- 월 식재료비 = 그 달에 납품 예정인 「발주 확정·입고 완료」 발주서 합계
- 월 매출 = 일마감에 입력한 식수 × 업장 단가

## 실제 데이터로 바꾸기

1. 재료 목록: 「재료·메뉴 관리 → 재료 → CSV 가져오기」
   형식 `재료명, 단위(kg·L·개), 단가, 업체명, 원산지, 알러지` (첫 줄 제목은 자동 인식, 같은 이름은 갱신, 없는 업체는 자동 등록)
2. 메뉴별 1인분 재료: 「메뉴·레시피」에서 입력 (대량 가져오기는 다음 단계)
3. 업장: 「업장 관리」에서 식수·단가·끼니 입력

## 아직 없는 것

- 로그인·권한 분리(업장 인력의 「입력 권한」은 저장만 되고 아직 막지 않음)
- 서버·DB 저장(지금은 브라우저에만 저장되어 PC가 바뀌면 보이지 않음)
- 메뉴·레시피 CSV 가져오기, 알러지 표시, 영양소 계산
- 세경유통 등 실제 발주서 양식 출력, 카카오톡·문자 발주 전송
